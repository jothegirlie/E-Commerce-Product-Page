👟 E-Commerce Shoe Shop

🚧 Work in Progress. This project is actively being built. Features, functionality, and design are subject to change!

📄 About:

A modern and responsive fashion e-commerce website built with React, featuring separate Home, About, Men, and Women sections. Users can browse products, filter items based on their preferences, and view individual product pages.

The project is also being developed with a PostgreSQL database and a backend authentication system, with plans to make user-specific features persist between sessions.

✨ Features:

🏠 Home Page — A welcoming landing page with an overview of the store and featured products.

🧭 React Router Navigation — Smooth navigation between the Home, About, Men, and Women sections.

ℹ️ About Page — Provides information about the website, brand, and overall concept.

👨 Men's Section — Dedicated product section featuring items for men.

👩 Women's Section — Dedicated product section featuring items for women.

🔎 Product Filtering — Filter products by categories, brands, colors, sizes, and price ranges.

❤️ Favorites — Users can save products to their favorites.

🛒 Shopping Cart — Add products to a cart and manage quantities and selected sizes.

🔐 User Authentication — User registration and login using password hashing and JWT authentication.

🗄️ PostgreSQL Database — Stores users, products, favorites, carts, and cart items.

🚧 Planned / In Progress:

- Persistent favorites that remain saved after logging out and logging back in.
- Persistent user-specific shopping carts.
- User-specific data stored in the database.
- Synchronization between the React Context state and PostgreSQL.
- More complete product and cart management.
- Further responsive design improvements.
- Additional UI and e-commerce features.
